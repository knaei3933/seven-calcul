## 1. 배경

- 고객(화장품 브랜드 등)이 **상품(제품)마다 견적서를 요청**하는 운영이 반복된다
- 현재는 고객 정보 없이도 견적서가 작성되어 이력에 남는다 → "어떤 고객 대상 견적인지" 알 수 없는 레코드가 쌓임
- SKU 제품명이 미입력 시 `充填物1`로 자동 치환되어, **상품 이름이 견적서에 안 나가는 경우**가 있음
- 반면 원가 시뮬레이터는 "계산기처럼" 조건만 바꿔 가격을 살펴보는 용도으로도 쓰인다 → **시뮬레이터는 자유롭게, 발행 시점에만 강제**해야 함

## 2. 핵심 개념: 「계산」과 「발행」의 분리

```
원가 시뮬레이터 (/)            견적서 페이지 (/quote)              이력 (/history)
┌────────────────┐   진행   ┌────────────────────┐   발행   ┌──────────────┐
│ 조건 입력·계산    │ ──────→ │ 고객 정보 입력(이동)  │ ──────→ │ PDF 출력       │
│ (계산기 모드 OK)  │         │ 견적서 편집·A4 미리보기│         │ 메일 작성      │
│ 고객 정보 UI 제거  │         │ 필수 정보 검증        │         │ 상태 관리      │
└────────────────┘         └────────────────────┘         └──────────────┘
```

- **시뮬레이터**: 견적 확정 의사 없이 자유롭게 계산 가능 (제품명 미입력·고객 미입력 허용)
- **발행**: 세금·금액·고객·제품명이 확정된 공식 견적서로, 이력에 영구 보존

## 3. 화면별 변경 사항

### 3.1 원가 시뮬레이터 (`/`)

| 변경 | 내용 |
|---|---|
| **고객 정보 패널 제거** | 「顧客情報」섹션(고객코드·마스터 검색·저장·일람)을 `/quote`로 이동. 시뮬레이터는 제품 조건과 계산에 집중 |
| 「見積書発行へ進む」유지 | 버튼 클릭 시 **사전 검증**: SKU 제품명 미입력이 있으면 /quote 진입을 차단하고 입력 요청 (진행 의사가 있으므로 이 시점에 검증) |
| 제품명 플레이스홀더 유지 | 시뮬레이터 내 계산에는 `充填物N` 기본값 사용 가능 (계산기 모드 보장) |

### 3.2 견적서 페이지 (`/quote`)

| 변경 | 내용 |
|---|---|
| **고객 정보 섹션 신설** | 상단(또는 좌측 패널 상단)에 「顧客情報」블록: 고객코드 입력 → 마스터 자동 읽기 → 미등록 시 신규 저장. 회사명·담당자·우편번호·주소·전화·이메일 입력란 |
| **「履歴に保存」→「見積書を発行」** | 버튼명·모바일 하단 버튼 일괄 변경. 발행 개념으로 통일 |
| **발행 필수 검증** | 하기 4장 참조. 미충족 시 발행 버튼 비활성 + 부족 항목 안내 |
| SKU 제품명 | 사양 섹션의 SKU 표시에 제품명 반영(이미 반영됨). 발행 시 전 SKU 입력 확인 |
| A4 미리보기 | 기존 A4 시트 그대로 (UI 내 미리보기 기능은 이미 충족, 유지·개선) |
| 발행 완료 안내 | "견적서를 발행했습니다 → 이력에서 PDF 출력·메일 발송이 가능합니다" + 이력으로 이동 버튼 |

### 3.3 견적 이력 (`/history`)

| 변경 | 내용 |
|---|---|
| **PDF 출력 버튼** | 목록 카드 및 상세 화면에 「PDF出力(A4)」버튼 → 브라우저 인쇄(PDF 저장) 호출 (기존 A4 고정 출력 활용) |
| **메일 작성 버튼** | 「メール作成」→ mailto 링크로 메일 앱 자동 작성 (수신자=고객 이메일, 제목=見積書番号, 본문=금액 요약) ※첨부는 수동 |
| 상태 연동 | 메일 작성 완료 시 상태를 `sent`로 변경하는 버튼 제공 |
| 고객 미입력 구 레코드 | 기존 데이터는 수정하지 않고 「得意先未入力」배지 표시 |

## 4. 발행 필수 입력 검증 규칙 (안)

| # | 항목 | 필수 시점 | 비고 |
|---|---|---|---|
| 1 | 会社名(得意先名) | **발행** | 공백 불가. 마스터 읽기 또는 수동 입력 |
| 2 | SKU별 제품명(全SKU) | **/quote 진입 + 발행** | `充填物N` 자동 채움은 시뮬레이터 계산에만 허용 |
| 3 | 원가 연동 상태 | 발행 | 기존 stale 검증 유지 (시뮬레이터 조건 변경 시 재계산 필요) |
| 4 | 見積番号·발행일·유효기한 | 발행 | 자동 생성값 확인 (형식 S7-YYYYMM-001) |
| 5 | 고객 이메일 | **메일 발송 시** | 발행 자체에는 불필요, mailto 시 형식 검증 |

- 검증은 **UI(버튼 비활성+안내)와 API(서버 재검증) 이중**으로 구현
- 고객 마스터 저장 규칙(고객코드+회사명 필요)은 기존 유지

## 6. 데이터·상태 변경

- DB 스키마 변경 **없음** (고객 필드는 quotations 테이블에 이미 존재)
- API `validateQuotationInput`에 발행 검증 추가 (회사명·SKU명)

- 시뮬레이터 초안(draft)에는 고객 정보를 담지 않고 /quote에서 입력 (기존 sessionStorage 전달 구조 단순화)

## 10-1. 필름 비용 구조 — 「관리는 단순, 계산은 정확, 공개는 총액」

**심화 검토 결과(원본 xlsx 259행 전수 검증)**: 올인원 단가 평탄화는 **불가**.
배송회수가 원반폭(500m/400m 단위)·발주길이·생산배율(736mm는 2배)로 계단 변동하여
같은 티어 안에서도 환산 m단가가 달라짐 (예: 570mm以下 1000m=294.6 → 1100m=307.1 円/m, 미회수 4.1%).

**확정 구조**:

| 역할 | 내용 |
|---|---|
| **카네이 관리 (마스터)** | **기본 m단가 6개만** — 570mm以下 328/252/226 · 571〜740mm 365/280/252 (500/1000/1500m 티어) |
| **시스템 자동 계산 (내부)** | 하기 검증 완료 규칙표 참조 — 코드와 xlsx 전수 일치 확인됨 |
| **외부 공개** | 시뮬레이터·견적서·체크리스트 모두 **フィルム費用 총액 1줄** (배송·통관 내역 비공개) |

**검증 완료 규칙표 (원본 xlsx 259행 100% 일치)**:
| 규칙 | 값 |
|---|---|
| 배송단위(폭별) | 500m: 356·368·396·464·476·512·**736(생산 2배)** ／ 400m: 556·580·620 |
| 배송회수 | `ceil(検討長さ ÷ 단위)`, 検討長さ=実発注長さ×생산배율 |
| 국내배송 | 2,000円/回 |
| 해외배송 | 16,000円/回 |
| 통관 | フィルム代 > 200,000円 → 6,600円 고정 / 이하 → 200円×회수 |
| 총액 | フィルム代＋国内＋海外＋通関 |
| 티어 | 実発注長이 <1000m→500티어, <1500m→1000티어, ≥1500m→1500티어 |

- 현행 코드(`shippingUnitForWidth`·`shippingTrips`·통관 분기)가 위 규칙과 **전수 일치** → 계산 로직 수정 불필요
- **736mm×2배 실구동 검증(2026-10-09)**: 발주 1,000m→4회·총 358,600엔, 1,500m→6회·총 492,600엔 — 원본 표와 전액 일치 확인
- (선택 개선) 368mm폭을 500m 리스트에 명시(현재는 fallback으로 동일 결과)
- 기존 데이터 호환: 구 견적 저장 내역은 이력 표시만 유지, 신규는 총액 공개만

**카네이무역 확인서 (신규 작성)**: `docs/film-price-verification.md`
- 관리 대상 기본단가 6종·자동계산 룰·검산 예시 4건(476mm 1,000/1,100m, 580mm 900m, 736mm×2배 1,000m)·FAQ·시스템 검증 결과
- 일본어 전개형 작성 — 계산기로 단계별 검산 가능, 비개발자(카네이 담당자) 확인용

**관리용 단가표(신규 작성)**: `/root/pouch_film_price_master_v2.xlsx`
- Sheet1「단가マ스터」: 기본 m단가 6행 + 적용기간(월 단위) — **카네이가 갱신하는 유일한 시트**
- Sheet2「자동계산ルール」: 배송단위·단가·통관 규칙(시스템 고정, 참고용)
- Sheet3「검証表」: 대표폭×길이별 총액·환산 m단가(계단 변동 확인용)

## 10-2. 카네이무역 → 세븐화학 필름 견적서 (일본 포멀 서식)

**목적**: 세븐화학이 파우치 견적을 발행할 때마다, 카네이무역 명의의 필름 견적서를 **자동 발행**(마스터 단가=이미 승인된 가격이므로 별도 승인 없음 — 기존 합의).

**발행 타이밍**: 파우치 견적서 발행(見積書を発行)과 동시에 자동 생성 · 세븐화학 구매 결재에 첨부

**서식 (일본 견적서 관행 준수)**:
| 항목 | 내용 |
|---|---|
| 발행자 | カネイ貿易(주소·TEL·FAX·담당자) — **정식 회사 정보 사용자 제공 필요** |
| 수신자 | 株式会社セブン化学 |
| 견적번호 | 예: `K-YYYYMM-###` (파우치 견적번호와 상호 참조) |
| 발행일·유효기한 | 발행일 + 1개월 (필름 단가 유효기간과 정렬) |
| 품목 | 필름 구성(예: PET12+AL7+PET12+LLDPE50μ)·原反幅·発注長さ |
| 수량/단가/금액 | m / **올인원 円/m (고정)** / 금액 |
