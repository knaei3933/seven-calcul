# フィルム原価計算の確認書（カネイ貿易向け）

作成日: 2026-10-09 ／ 対象: パウチ原価システムのフィルム費計算

---

## 1. この資料の目的

カネイ貿易が管理するフィルム単価について、
**「どの値を管理し、システムがどう計算するか」を電卓で検算できる形**で説明します。

- 管理するのは **基本m単価 6つだけ** です（月次更新）
- 配送費・通関料はシステムが自動計算します（本資料のルールどおり）
- 元表（`pouch_film_price_all_sizes_500mplus.xlsx`）の全259行と
  システム計算が一致していることを 2026-10-09 に検証済みです

## 2. 管理する基本m単価（月次更新・6つのみ）

| 価格帯（原反幅） | 〜999m | 1,000〜1,499m | 1,500m〜 |
|---|---|---|---|
| 570mm以下 | 328 | 252 | 226 |
| 571〜740mm | 365 | 280 | 252 |

※ 単位は 円/m。発注長さで tier が決まります。

## 3. 自動計算ルール（システム固定・変更不要）

| 項目 | ルール |
|---|---|
| 配送単位 | **500m/回**: 原反幅 356・368・396・464・476・512・**736mm** ／ **400m/回**: 556・580・620mm |
| 配送回数 | **切り上げ(検討長さ ÷ 配送単位)** ／ 検討長さ＝発注長さ×生産倍率 |
| 生産倍率 | 通常 1倍。**736mm幅で生産する 35×60・35×80・Xra38.5×90 は 2倍**（必要長900m超で切替） |
| 国内配送費 | 2,000円 × 回数 |
| 海外配送費 | 16,000円 × 回数 |
| 通関料 | フィルム代 **200,000円超 → 6,600円固定** ／ 以下 → 200円 × 回数 |
| 総額 | フィルム代 ＋ 国内 ＋ 海外 ＋ 通関 |

## 4. 計算手順（かんたん3ステップ）

```
① フィルム代 ＝ 発注長さ × 基本m単価（tierは発注長さで決まる）
② 配送回数 ＝ 切り上げ（発注長さ × 生産倍率 ÷ 配送単位）
③ 総額 ＝ ① ＋ 2,000×回数 ＋ 16,000×回数 ＋ 通関料
```

## 5. 検算例（電卓で確認できます）

### 例1）原反幅476mm・発注1,000m（標準）

| 手順 | 計算 | 結果 |
|---|---|---|
| フィルム代 | 1,000 × 252（1,000m tier・570以下） | 252,000円 |
| 検討長さ | 1,000 × 1倍 | 1,000m |
| 配送回数 | 1,000 ÷ 500 → 切り上げ | **2回** |
| 国内＋海外 | (2,000＋16,000) × 2 | 36,000円 |
| 通関料 | 252,000 ＞ 200,000 → | 6,600円 |
| **総額** | | **294,600円**（換算 294.6円/m） |

### 例2）原反幅476mm・発注1,100m（同じtierなのに注意）

| 手順 | 計算 | 結果 |
|---|---|---|
| フィルム代 | 1,100 × 252 | 277,200円 |
| 配送回数 | 1,100 ÷ 500 → 切り上げ | **3回**（1,000mは2回） |
| 国内＋海外 | 18,000 × 3 | 54,000円 |
| 通関料 | 277,200 ＞ 200,000 | 6,600円 |
| **総額** | | **337,800円**（換算 307.1円/m） |

→ **同じtierでも配送回数の段差で m単価が変わる**ため、
「配送込みの平坦な単価」にはできません（管理は基本単価のみで正確）。

### 例3）原反幅580mm・発注900m（400m単位の幅）

| 手順 | 計算 | 結果 |
|---|---|---|
| フィルム代 | 900 × 365（571〜740・〜999m tier） | 328,500円 |
| 配送回数 | 900 ÷ **400** → 切り上げ | **3回** |
| 国内＋海外 | 18,000 × 3 | 54,000円 |
| 通関料 | 328,500 ＞ 200,000 | 6,600円 |
| **総額** | | **389,100円** |

### 例4）736mm幅×2倍生産・発注1,000m（35×60等の大型ロット）

| 手順 | 計算 | 結果 |
|---|---|---|
| フィルム代 | 1,000 × 280（**571〜740帯を自動適用**・1,000m tier） | 280,000円 |
| 検討長さ | 1,000 × **2倍** | 2,000m |
| 配送回数 | 2,000 ÷ 500 → 切り上げ | **4回** |
| 国内＋海外 | 18,000 × 4 | 72,000円 |
| 通関料 | 280,000 ＞ 200,000 | 6,600円 |
| **総額** | | **358,600円** |

→ 736mm×2倍は「250mごとに1回」のように見えますが、
実際は **「500m単位 × 検討長さ(発注×2)」** のルールです。システムはこのとおり計算します。

## 6. よくある質問

**Q. なぜ1,100mの方が1,000mより m単価が高いの？**
A. 配送が500mごとの段差（2回→3回）になるためです。基本単価は同じ252円/mです。

**Q. 736mm幅の配送回数が多いのはなぜ？**
A. 2倍生産のため検討長さが2倍になり、その分の配送として計上されるからです（元表と同じ規則）。

**Q. 通関料が急に6,600円になるのは？**
A. フィルム代が200,000円を超えたタイミングで 200円×回数 → 6,600円固定 に切り替わるためです。

**Q. どこで確認できるの？**
A. 管理用ブック `/root/pouch_film_price_master_v2.xlsx` の
**Sheet3「検証表」**（代表幅×長さの総額・換算m単価）や、元表の該当行と突き合わせてください。

## 8. 運用のまとめ

1. **月次で基本m単価6つを更新**（管理用ブック Sheet1 / システムの管理画面）
2. 配送・通関は **システムが自動計算**（本資料のルールどおり・元表と一致検証済み）

4. カネイ→セブン化学のフィルム見積書も **総額＋換算m単価** で自動発行（計画中）
